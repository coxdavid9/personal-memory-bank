# Personal Memory Bank

A simple personal and work memory system: brain-dump anything, organize it with AI, and turn items that need action into plans and reminders.

## V1 goals
- One-box brain dump
- AI categorization: Remember, Do, Improve, Idea
- Due dates and reminders
- Simple daily "What needs my attention?" view
- Searchable memory
- Google Calendar integration as an optional feature

The app should stay intentionally simple: the user should spend almost no time maintaining the system.
